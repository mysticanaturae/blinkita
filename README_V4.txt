BLINKITA SI V4 — BILINGUAL

Start here:
- index.html = language selector
- sl/ = Slovenian version
- en/ = English version

Shared assets:
- css/ = global and portal styles
- js/navigation.js = shared navigation + language-aware labels
- js/tzolkin.js = Tzolk’in calculation
- js/main.js = page initialization

Language switching is available on every page. The Slovenian and English versions use the same structure so new modules can be added in parallel.

Important: Tzolk’in remains a shared calculation layer; the language changes the interface text, not the underlying count.
